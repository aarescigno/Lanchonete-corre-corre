# Lanchonete Corre-Corre

Jogo de navegador de gerenciamento de restaurante, em português do Brasil.
Você é a Bia, a garçonete, e trabalha com o Chef Tonhão para atender a
freguesia, fazer a lanchonete crescer e pagar as contas.

Código em `src/`; o jogo montado é o `lanchonete.html`.
