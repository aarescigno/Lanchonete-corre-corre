# Kits para começar projetos novos

O fluxo de trabalho da Lanchonete Corre-Corre, pronto para levar a outros projetos. Cada kit tem um `instalar.py`, um `LEIA-ME.md` e a pasta `modelo/`.

| Kit | Para quê | Baixar |
|---|---|---|
| `neutro/` | Qualquer projeto, em qualquer linguagem: só o fluxo (regras do `CLAUDE.md`, docs, ferramentas, testes resumidos) | `kit-neutro.zip` |
| `jogo-manager/` | Jogo de navegador num HTML só, no estilo simulador de gestão: o fluxo mais um esqueleto de jogo que já funciona (simulação, save, harness, lote, capturas) | `kit-jogo-manager.zip` |

Para baixar, abra o `.zip` no GitHub e use "Download raw file". Depois de mudar um kit, refaça os zips com `python3 kits/empacotar.py`.
