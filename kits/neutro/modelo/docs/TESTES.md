# Testes: detalhes (só quando o assunto pedir)

O resumo está no `CLAUDE.md`; aqui fica o que não precisa estar em todo turno: variáveis de ambiente, dados de teste, coordenadas, alvos de desempenho e o histórico de ajustes.

## Como rodar
- `ferramentas/testar.sh` (rápidos) e `ferramentas/testar.sh --tudo` (com os lentos); a lista está em `ferramentas/testes.txt`.
- Para a saída caber em poucas linhas, cada teste termina com uma linha de resumo (ex.: `12 verificações, fails = 0`) e marca cada erro com `FAIL` no começo da linha.
